额度与接入方式

个人业务默认每 Key 3,000 点/日，人工审核最高 6,000 点；公开业务全部人工审核，10,000 点为参考申请额度。仅个人首把且不超过 3,000 点可自动批准。第二把、增额及业务资料变更需说明原因并审核。

每把 Key 独立计算日额度、每分钟 60 点、并发 1；所有 Key 无限期。search / related / artists 分别消耗 3 / 2 / 1 点，health 不计点。每天北京时间 00:00 重置，不结转。

无 Key 共享 15,000 点/日、30 点/分钟、并发 1。全受治理 REST 同时最多 2 个业务请求，search 最多 1 个、推荐合计最多 1 个，每分钟 120 点。网页和 MCP 不使用这些额度。

在服务器安全保存 Key。个人业务发送 Bearer Key 与登记的 Client；公开业务还须发送登记的 Site，按原样精确匹配。Key 不应放在公开网页或代码中。

Authorization: Bearer <API_KEY>
X-DanbooruSearch-Client: <登记的 Client>
X-DanbooruSearch-Site: <公开业务登记的 HTTPS Site>

明确执行失败或超时退还日点数，短时令牌不退；轮换不重置用量，旧 Key 立即失效。429 请按 Retry-After 退避，401 检查凭证，403 核对登记头，503 稍后重试。
