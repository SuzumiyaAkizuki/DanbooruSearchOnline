来源概览

来源为自声明或粗粒度归因，不是已验证用户。“未声明”不等于无 Key，也不能区分具体调用者。

客户端分布

客户端类别不是独立用户数，同一类别可能对应多个服务。

观测压力

HTTP 在途峰值包含等待，不是同时运行的模型任务数。分钟峰值取来源 / 客户端 / 接口分组的最大值，不是全站 RPM；各组峰值不能相加。
